# gstack (GitHub repo)

> [raw source](../../raw/2026-09-27-gstack.md) · Garry Tan (YC President & CEO) ·
> code repo, v1.91.2.0, MIT. **Playbook: [[gstack]].**

## TL;DR
A free, open-source pack of about 55 Markdown **skills** plus helper tools that turn
[[claude-code|Claude Code]] into a "virtual engineering team": CEO, eng manager,
designer, reviewer, QA lead, security officer, release engineer. The skills run as
one **sprint** (Think → Plan → Build → Review → Test → Ship → Reflect), and each
step's output feeds the next.

## Key takeaways
1. **A process, not a toolbox.** `/office-hours` writes a design doc →
   `/plan-ceo-review` and `/plan-eng-review` read it → `/review` → `/qa` → `/ship`
   → `/retro`. `/autoplan` runs all the plan reviews in one go.
2. **The process is what makes parallel agents workable.** The author runs 10–15
   Claude Code sessions at once in Conductor. "Without a process, ten agents is ten
   sources of chaos."
3. **Safety tools:** `/careful` warns before destructive commands, `/freeze` limits
   edits to one folder, `/guard` does both.
4. **Memory across sessions:** `/learn`, `/context-save` and `/context-restore`, and
   optionally GBrain.
5. **Ethos is "Boil the Ocean":** AI makes completeness cheap, so build the complete
   version, with tests. This is the opposite of [[ponytail|Ponytail]]'s [[yagni]]
   stance.
6. **Privacy:** telemetry is opt-in and off by default; every off-machine send is
   logged locally.
7. **Author's claims:** about 810× his 2013 coding pace, 3 production services and
   40+ features in 60 days, part-time. These are self-reported, with a published
   methodology.

## Notable claims
- "gstack is a process, not a collection of tools."
- "The sprint structure is what makes parallelism work."
- "Tests make vibe coding safe instead of yolo coding."
- Requirements: Claude Code, Git, Bun; Node on Windows. Browser skills use the Aside
  browser (macOS) or a bundled Chromium.

## Trial in this vault's cloud session (2026-09-27)
Installed from source with `./setup` (browser skipped). Measured with the bundled
`gstack-context-bill`:
- **Always-on:** 55 skill descriptions, about **7K tokens** loaded into every session.
- **Per use:** each skill's instructions load when invoked, **3K–51K tokens**. For
  example `/ship` is about 51K, `/plan-ceo-review` about 39K, `/office-hours` about
  33K, `/review` about 27K.
- Setup added no hooks here (the optional timeline hook was turned off), and
  telemetry stayed off.
